# Invitación XV Años · Fernanda 👑

Invitación web con temática de Aurora (La Bella Durmiente) en fiusha y dorado.
Comienza con un libro de cuento que se abre.

## Editar datos
Todo se cambia en **`js/config.js`** (nombre, fecha, padres, padrinos, itinerario, regalos, RSVP).

- **Música:** pon tu archivo en `assets/music/cancion.mp3`
- **Foto (opcional):** pon la imagen en `assets/img/` y escribe la ruta en `foto`

## Publicar en GitHub Pages
1. Crea un repositorio y sube todos los archivos (index.html en la raíz).
2. Settings → Pages → Source: *Deploy from a branch* → rama `main`, carpeta `/ (root)`.
3. En un par de minutos estará en `https://TU-USUARIO.github.io/NOMBRE-REPO/`.
